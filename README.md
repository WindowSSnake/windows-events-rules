Windows 事件规则库。中文描述 + 严重度分级 + 排查建议。



## 字段



* `source` 事件提供程序名
* `event\_id` Windows 事件 ID
* `level` Windows 原生级别（Critical/Error/Warning/Information/Verbose）
* `severity` 业务严重度（Critical/High/Medium/Low）
* `title` 中文摘要
* `description` 事件含义
* `suggestion` 排查建议
